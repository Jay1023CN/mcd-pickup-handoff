# 90 秒演示：这顿麦当劳，帮我取一下

已录制[44 秒操作视频](https://mcd-pickup-handoff.epic-rain-2778.chatgpt.site/watch.html)，390×844 手机画面，无音频。播放页使用 MP4，支持直接播放和下载。视频展示公网模拟页的实际点击，全程标注模拟数据；包含选单、生成、复制分享、朋友刷新与反馈取好。下面保留带口播的 90 秒录制方案。

录制入口：[手机模拟演示](https://mcd-pickup-handoff.epic-rain-2778.chatgpt.site/demo)。用 390px 手机画幅，发起人和朋友各开一个页面。订单操作画面始终保留“模拟数据”字幕，保留页面自带的模拟标记。

| 时间 | 画面与操作 | 口播 |
| --- | --- | --- |
| 00–10 秒 | 从顶部新 Logo 和“这顿麦当劳，帮我取一下”向下移到订单列表。 | 开会走不开，朋友刚好路过麦当劳。哪家店、几份餐、取餐码是多少？把这一单发给他就行。 |
| 10–24 秒 | 切到未配对首页，展示“下载 Windows 连接器”和扫码说明；再回到演示页。这里介绍首次连接，不拍 Token，也不把演示账户说成刚刚配对成功。 | 第一次，在 Windows 电脑打开免安装连接器，存好自己的 Token，手机扫一次码。不用注册，之后选单和分享都在手机上。 |
| 24–43 秒 | 选择“麦当劳 · 示例广场店”，看门店、餐品和“带上取餐码”；保持勾选，点“生成交接链接”。画面自动移到“发给朋友”。旁边短暂展示三个工具名：`order-list` → `query-order`，`now-time-info`。 | 选这笔到店订单，确认门店和餐品。取餐码默认带上，生成后就能发。接入真实账户时，MCP 先找订单，再查详情；生成和刷新都会重查，也会记录官方时间。 |
| 43–58 秒 | 用生成的链接打开朋友页。展示门店、餐品、A008 和查询时间，点“取餐前，刷新一次”；刷新结束后展示复制取餐码、复制门店地址和地图导航入口。 | 朋友打开链接，就能看地址、餐品和取餐码。到了店，先点刷新。地址和码能直接复制，也能打开地图，不用在聊天里来回找。 |
| 58–69 秒 | 依次点“我来取”“我到店了”“已帮你取好”。拍到朋友反馈及旧码收起，订单状态仍为“模拟 · 配餐中”。 | 朋友点一下，就能报进度。实际使用时，你在最近交接里就能看到。取好后，朋友页收起旧码；朋友反馈和官方订单状态分开显示。 |
| 69–77 秒 | 回到原发起人页面，点“撤销交接链接”；朋友页点“查看最新订单”，展示模拟撤销提示。 | 发错了还可以撤销。链接十分钟有效，朋友只看到这一单，Token 留在你的电脑。 |
| 77–90 秒 | 最后一屏显示文字：“真实 MCP：订单列表、历史详情、官方时间已查询；已完成订单禁止交接。手机操作画面：模拟订单。”保留 Logo。 | 真实接入已经查到订单列表和历史详情，已完成订单会拦截。今天用模拟订单演示；真实待取餐到门店的交接，还没有现场验收。 |

剪辑时给生成和刷新留一小段等待，不剪成瞬间成功。MCP 工具名作为说明字幕展示，不制作虚构调用日志。手机演示里的“已帮你取好”是模拟点击，不配实际取餐成功的字幕。真实查询事实来自[验证记录](VALIDATION.md)，不展示真实订单、取餐码或凭据。

## 操作核对

以下入口已在本机 Chromium 实际点击核对，与[README](../README.md)的手机流程一致。所有 `/demo` 操作均未发送 `/api/mobile` 请求。

| 演示动作 | Playwright 定位方式 | 已核对结果 |
| --- | --- | --- |
| 选到店订单 | `get_by_role('button', name=re.compile('示例广场店'))` | 出现详情及生成按钮；已完成和外送订单保留各自状态。 |
| 默认带码、生成 | `get_by_role('checkbox', name=re.compile('带上取餐码'))`；`get_by_role('button', name=re.compile('生成交接链接'))` | 复选框默认选中，生成 `/demo/take?code=yes` 链接。 |
| 读取分享链接 | `get_by_role('textbox', name='分享链接')` | 可将同一链接打开在朋友页面。录屏可直接打开此链接，不依赖分享面板是否支持桌面浏览器。 |
| 取餐前刷新 | `get_by_role('button', name='取餐前，刷新一次')` | 刷新后恢复模拟码 A008，按钮位于朋友反馈之前。 |
| 复制、地图 | `get_by_role('button', name='复制取餐码')`；`get_by_role('button', name='复制门店地址')`；`get_by_role('link', name=re.compile('地图导航'))` | 三个入口存在。演示地址为虚构地址，录屏展示地图入口即可。 |
| 朋友反馈 | `get_by_role('button', name=re.compile('我来取'))`；同样定位“我到店了”“已帮你取好” | 三步反馈成功；取好后隐藏码，`get_by_label('模拟订单状态')` 仍显示“模拟 · 配餐中”。 |
| 撤销 | `get_by_role('button', name='撤销交接链接')`；朋友页 `get_by_role('button', name='查看最新订单')` | 发起页撤销后，朋友刷新显示模拟交接卡已撤销。 |
| 新 Logo | `locator('img.brand-mark')` | 加载 `/brand/handoff-mark.svg`，实际尺寸 44×44，顶部可见红底餐袋与交接箭头。 |

公开演示页不展示本人“最近的交接”，因此 58–69 秒只拍朋友反馈，口播说明实际使用中的记录查看方式，不拼接成演示页自动出现记录。复制完成的提示可能因浏览器权限而不同；不支持剪贴板时，页面提供可选文字。

操作及 Logo 已对照 320px 和 390px 本机浏览器截图检查。截图只含未配对首页或模拟订单；录制新画面时从页面顶部开始，确保新版 Logo 和“模拟”标记一起入镜。现有视频为模拟流程，不含真实取餐画面。
